# MileVoxa Web v4.3.28 — Hero Responsive Scale

Built on v4.3.27.

The homepage hero now keeps more visual presence as the browser width changes.

## Responsive behavior
- large desktop: 520px hero
- standard desktop: 500px hero
- small desktop/tablet landscape: 470px split hero
- tablet portrait: 420px product visual
- mobile: 360px product visual

The artwork, crop, copy, buttons, and hero content are unchanged.
