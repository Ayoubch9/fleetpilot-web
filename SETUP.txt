FLEETPILOT WEB v1.4.0 — REAL PILOT AI

Keep your existing Supabase variables.

Add to .env.local:

OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_MODEL=gpt-5.6-luna

OPENAI_MODEL is optional.

Then:

cd C:\projects\fleetpilot_web
npm install
npm run typecheck
npm run build
npm run dev

Test:
http://localhost:3000/pilot-ai

For Vercel:
Project -> Settings -> Environment Variables
Add OPENAI_API_KEY
Optionally add OPENAI_MODEL
Then redeploy production.
