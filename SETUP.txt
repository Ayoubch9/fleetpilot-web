MILEVOXA WEB v4.4.0 — FREE PUBLIC BETA

1. Keep your existing .env.local and Supabase credentials.
2. Add:
   MILEVOXA_PUBLIC_BETA=true

   The app defaults to public beta if this variable is omitted, but setting it
   explicitly is recommended for production/staging clarity.

3. Run these SQL files in Supabase SQL Editor if not already applied:
   - supabase_public_beta_feedback_v4_4_0.sql
   - supabase_signout_feedback_v4_6_6.sql
   - existing project migrations required by your installation

4. Before production rollout, run the READ-ONLY audit:
   - supabase_public_beta_billing_audit_v4_4_0.sql

   If it returns active Stripe subscriptions, review those customers separately.
   This release does not cancel, refund, modify, or create subscriptions.

5. Install/check locally:

   cd C:\projects\fleetpilot_web
   npm install
   npm run typecheck
   npm run build
   npm run dev

Public beta behavior:
- no checkout/card required
- expired/active legacy trial users receive beta access
- paid checkout endpoint is blocked while beta is enabled
- existing paid billing records are preserved
- disabling beta does not create a charge or auto-enroll anyone
- future paid checkout still requires explicit owner action
